# 🍓 모아 캘린더

덕질 일정을 한곳에 모아 챙겨주는 데스크톱 캘린더예요.
예약 마감, 입금일, 발매·배송, 온리전, 최애 생일까지 — 놓치기 쉬운 일정을 소리 알림으로 챙겨줘요.

<br>

## ✨ 이런 걸 할 수 있어요

- **캘린더** — 월간/주간으로 일정 한눈에. 날짜에 마우스만 올려도 그날 일정이 쫙 떠요.
- **소리 알림** — 일정 시각(또는 1분·5분·30분·1시간 전)에 소리로 알려줘요. 소리 종류도 4가지 중에 고를 수 있어요.
- **할일** — 오늘 할일을 적어두고, 못 끝낸 건 다음 날로 넘어와요(며칠째 밀렸는지도 알려줘요).
- **메모** — 예약 도안 번호, 계좌, 아이디어 등 빠르게 적어두기.
- **일정 종류** — 예약마감·입금일·발매·이벤트·생일·창작마감 색깔로 구분. 직접 추가·수정도 가능.
- **테마** — 6가지 색(보라·딸기우유·하늘·민트·선셋·포도) + 라이트/다크. 색을 바꾸면 배경도 같이 물들어요.

<br>

## 📥 다운로드 & 설치

1. 오른쪽 [**Releases**](../../releases) 에서 최신 버전의 `모아 캘린더 Setup.exe` 를 받아요.
2. 받은 파일을 더블클릭해서 설치해요.
3. 설치 중 **"Windows의 PC 보호"** 또는 **"알 수 없는 게시자"** 경고가 뜰 수 있어요.
   - 이건 개인 개발자가 만든 앱이라 뜨는 정상적인 안내예요.
   - **"추가 정보" → "실행"** 을 누르면 설치돼요.
4. 설치가 끝나면 바탕화면과 시작 메뉴에 아이콘이 생겨요. 🎉

<br>

## 💡 쓰는 법

- **일정 추가**: 날짜를 누르고 `+ 일정` 버튼, 또는 오른쪽 `이 날에 일정 추가`.
- **알림 켜기**: 일정에 시각을 넣고 알림을 켜면, "언제 알릴까요?"에서 미리 알림 시간을 고를 수 있어요.
- **소리 고르기**: 오른쪽 위 ⚙️ 톱니바퀴 → 알림 → 소리 종류에서 골라요(눌러서 미리듣기 가능).
- **테마 바꾸기**: ⚙️ 톱니바퀴 → 테마에서 색과 라이트/다크 선택.
- **창 닫기**: 닫아도 완전히 꺼지지 않고 작업표시줄 우측 트레이로 내려가서 **알림을 계속 받아요**.
  완전히 끄려면 트레이 아이콘을 우클릭 → 종료.

<br>

## 💾 내 일정은 어디에 저장되나요

모든 일정·할일·메모·설정은 내 컴퓨터 안에만 저장돼요. 인터넷에 올라가지 않아요.

```
C:\Users\(내 계정)\AppData\Roaming\모아 캘린더\moa-data.json
```

이 파일을 복사해두면 백업이 되고, 다른 컴퓨터에 옮겨 붙이면 그대로 이어서 쓸 수 있어요.
